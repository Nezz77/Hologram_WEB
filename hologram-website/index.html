// 01 — ABOUT

What We Built

Fusion 5 engineered a full-stack holographic display system — spanning mechanical design, custom PCB fabrication, firmware, wireless power, and real-time image rendering.

The Hologram Array uses the persistence-of-vision (POV) principle: a 200-LED strip mounted on a rotating arm spins at 700 RPM. By precisely timing individual LED illumination to angular position, the system paints a full 3D image suspended in mid-air with no screen.

Power is transferred wirelessly to the rotating assembly via resonant inductive coupling. The entire control stack runs on an ESP32 communicating with a host PC over Wi-Fi.

// 03 — PROCESS

Build Timeline

✓
PHASE 01 · JAN

Concept & Research

POV holography research, feasibility study, and component shortlisting. Defined RPM targets, LED density, and power budget.

✓
PHASE 02 · FEB–MAR

CAD & PCB Design

SolidWorks 3D models for all mechanical parts. KiCad PCB layout for the rotating LED board and the stationary base. Coil geometry optimized for WPT.

✓
PHASE 03 · APR

Fabrication & Assembly

3D printing of motor mount, coil holders, frame, and spacers. PCBs fabricated and assembled. Motor and LED strip mounted and balanced.

✓
PHASE 04 · MAY

Firmware & Software

ESP32 firmware for hall-effect triggered POV rendering. Python host for polar-to-Cartesian image mapping and Wi-Fi streaming.

✓
PHASE 05 · JUN

Interim Showcase

First public demonstration with partial image rendering. Demonstrated wireless power and basic POV patterns to faculty reviewers.

★
PHASE 06 · AUG

Final Evaluation

Full-color 3D image display operational. Live demo to evaluators with real-time image switching via host PC. Project successfully completed.
